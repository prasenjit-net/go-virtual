Admin API Reference

Complete reference for all REST endpoints under /_api/. All endpoints return JSON. All write operations accept Content-Type: application/json.

ℹ️
Base URL All endpoints are relative to http://<host>:<port>/_api. In headless mode (--headless), all /_api/ endpoints are disabled.

Authentication

The Admin API has no built-in authentication. In production, protect it with a reverse proxy (e.g., nginx with basic auth) or network-level access controls (firewall, VPN). Never expose it publicly without protection.

Specs

GET
/_api/specs
List all uploaded specs.
POST
/_api/specs
Upload a new OpenAPI 3 spec.
// Request body
{
  "name": "string",          // Required. Display name
  "content": "string",       // Required. YAML or JSON OpenAPI 3 content
  "basePath": "string",     // Optional. Mount path prefix
  "backendUri": "string"    // Optional. Upstream backend URL
}
GET
/_api/specs/:id
Get a single spec by ID.
PUT
/_api/specs/:id
Update a spec (re-parse operations with new content).
DELETE
/_api/specs/:id
Delete a spec and all its associated operations and responses.
PUT
/_api/specs/:id/enable
Enable a spec (makes its operations active).
PUT
/_api/specs/:id/disable
Disable a spec (operations stop responding).
PUT
/_api/specs/:id/tracing
Toggle tracing for a spec.
{ "enabled": true }
PUT
/_api/specs/:id/example-fallback
Enable or disable OpenAPI example/default fallback for standard mode.
PUT
/_api/specs/:id/backend
Set or clear the upstream backend URI for proxy mode.
PUT
/_api/specs/:id/mode
Select the spec mode: standard, ai, or proxy.

Operations

GET
/_api/specs/:specId/operations
List all operations for a spec.
GET
/_api/operations/:id
Get a single operation by ID.
GET
/_api/operations/:id/signature
Get the request signature configuration for an operation.
PUT
/_api/operations/:id/signature
Update the request signature configuration for an operation.

Operation response object

{
  "id": "op_abc",
  "specId": "spec_xyz",
  "operationId": "getPet",
  "method": "GET",
  "path": "/pets/{id}",
  "summary": "Get a pet by ID",
  "tags": ["pets"],
  "responseCount": 2,
  "scriptBindingCount": 1
}

Responses

GET
/_api/operations/:operationId/responses
List all response configs for an operation, ordered by priority.
POST
/_api/operations/:operationId/responses
Create a new response config for an operation.
// Request body
{
  "name": "string",          // Required
  "priority": 0,             // Required. Lower = evaluated first
  "statusCode": 200,         // Required
  "headers": {},              // Optional. Key-value pairs (values are templates)
  "body": "string",          // Optional. Response body (template)
  "conditions": [],          // Optional. Array of condition objects
  "delay": 0,                // Optional. Artificial delay in ms
  "tag": "default"         // Optional. Tag for organization
}
GET
/_api/responses/:id
Get a single response config.
PUT
/_api/responses/:id
Update a response config.
DELETE
/_api/responses/:id
Delete a response config.
PUT
/_api/responses/:id/priority
Update only the priority of a response config.
{ "priority": 5 }

Condition object schema

{
  "source": "path" | "query" | "header" | "body" | "signature",
  "key": "string",
  "operator": "eq" | "ne" | "gt" | "lt" | "gte" | "lte"
    | "contains" | "notContains" | "startsWith" | "endsWith"
    | "exists" | "notExists" | "regex",
  "value": "string"   // Not required for "exists"/"notExists"
}

AI

/_api/ai/status

/_api/scripts/ai-generate

Scripts

GET
/_api/scripts
List all scripts.
POST
/_api/scripts
Create a new script.
{
  "name": "string",
  "source": "string",     // Starlark code with def run(req)
  "timeoutMs": 100
}
GET
/_api/scripts/:id
Get a script by ID (includes source code).
PUT
/_api/scripts/:id
Update a script. Invalidates the compiled cache.
DELETE
/_api/scripts/:id
Delete a script. Fails if the script has active bindings.
POST
/_api/scripts/validate
Validate Starlark syntax without saving.
// Request
{ "source": "def run(req):\n  return {}" }

// Response
{ "valid": true, "errors": [] }
// or
{ "valid": false, "errors": ["line 1: syntax error"] }
POST
/_api/scripts/:id/test
Execute a script with a mock request and return the output.
// Request
{
  "req": {
    "path": { "id": "42" },
    "query": { "debug": "true" },
    "header": { "authorization": "Bearer test" },
    "body": { "quantity": 3 }
  }
}

// Response
{
  "output": { "total": 29.97 },
  "logs": ["Computing order for 42"],
  "executionMs": 3,
  "error": ""
}

Script Bindings

GET
/_api/operations/:operationId/scripts
List all script bindings for an operation.
POST
/_api/operations/:operationId/scripts
Bind a script to an operation.
{
  "scriptId": "string",
  "outputKey": "string"   // Used in templates as {{.script.outputKey.field}}
}
PUT
/_api/operations/:operationId/scripts
Replace all script bindings for an operation.
DELETE
/_api/operations/:operationId/scripts/:bindingId
Remove a specific script binding.

Global Store

GET
/_api/store
List all global store entries.
GET
/_api/store/:key
Get a single store entry by key.
// Response
{ "key": "myKey", "value": "myValue" }
PUT
/_api/store/:key
Create or update a store entry.
{ "value": "string" }
DELETE
/_api/store/:key
Delete a single store entry.
DELETE
/_api/store?confirm=true
Clear the entire global store. Requires confirm=true query parameter.

Sessions

GET
/_api/sessions
List all active sessions.
{
  "sessions": [
    {
      "id": "string",
      "createdAt": "RFC3339",
      "lastActivityAt": "RFC3339",
      "storeKeyCount": 0
    }
  ]
}
GET
/_api/sessions/:id
Get a session's details including its full store contents.
DELETE
/_api/sessions/:id
Invalidate (delete) a specific session.
DELETE
/_api/sessions?confirm=true
Invalidate all active sessions. Requires confirm=true.

Traces

GET
/_api/traces
List traces with optional filtering and pagination.

Query parameters

ParameterDescription
limitMax results (default: 100, max: 1000)
offsetPagination offset (default: 0)
specIdFilter by spec ID
operationIdFilter by operation ID
qFull-text search query
GET
/_api/traces/:id
Get a single trace by ID with full request/response/script details.
DELETE
/_api/traces
Clear all stored traces.
WS
/_api/traces/stream
WebSocket endpoint for real-time trace streaming. Each message is a full trace JSON object.
// Connect
ws://localhost:8080/_api/traces/stream

// Optional query params
ws://localhost:8080/_api/traces/stream?specId=spec_xyz

Statistics

GET
/_api/stats
Get global statistics.
GET
/_api/stats/specs/:specId
Get statistics for a specific spec.
GET
/_api/stats/operations/:operationId
Get statistics for a specific operation.
POST
/_api/stats/reset
Reset all statistics counters to zero.

Prometheus Metrics

GET
/_prometheus
Prometheus text format metrics endpoint. Suitable for scraping by Prometheus or any compatible monitoring tool.

Error Responses

All API errors return a JSON body with an error field:

{
  "error": "Spec not found",
  "code": "NOT_FOUND"
}
HTTP StatusMeaning
400 Bad RequestInvalid request body, missing required fields, or invalid values
404 Not FoundThe requested resource ID does not exist
409 ConflictResource conflict (e.g., deleting a script with active bindings)
422 Unprocessable EntityThe spec could not be parsed as valid OpenAPI 3
500 Internal Server ErrorUnexpected server-side error
